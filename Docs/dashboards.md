# 📊 تفاصيل الداشبوردات الثلاث — Dashboards

## 👤 داشبورد العميل (Client Dashboard) — 7 صفحات

### Layout
- **Sidebar:** قائمة جانبية responsive (تختفي على الموبايل)
- **Top Bar:** اسم المستخدم + إشعارات + avatar
- **تصميم:** بسيط وأنيق مع لمسات ذهبية

### الصفحات

#### 1. نظرة عامة (`/client/dashboard`)
| العنصر | الوصف |
|--------|-------|
| بطاقة الحجوزات القادمة | عدد الحجوزات + أقرب حجز مع countdown |
| آخر الرسائل | آخر 3 محادثات مع المرشدين |
| برامج مقترحة | 4 برامج بناءً على سجل التصفح/المفضلة |
| النشاط الأخير | Timeline آخر الإجراءات |

#### 2. حجوزاتي (`/client/bookings`)
| العنصر | الوصف |
|--------|-------|
| Tabs | قادمة / سابقة / ملغية |
| كروت الحجوزات | صورة البرنامج + التاريخ + المرشد + الحالة |
| فلترة | بحث بالتاريخ أو اسم البرنامج |

#### 3. تفاصيل حجز (`/client/bookings/[id]`)
| العنصر | الوصف |
|--------|-------|
| معلومات البرنامج | الاسم، التاريخ، المدة، عدد المشاركين |
| Timeline الحالة | مؤكد → قيد التنفيذ → مكتمل |
| بيانات المرشد | اسم + تواصل |
| تفاصيل الدفع | التكلفة المفصلة (سعر + رسوم + ضرائب) |
| إجراءات | إلغاء / تقييم / فتح نزاع |

#### 4-7. المفضلة، المراسلات، المدفوعات، الملف الشخصي
- تصميم متسق مع باقي الداشبورد
- responsive وسريع التحميل

## 🧭 داشبورد المرشد (Guide Dashboard) — 7 صفحات

### Layout
- **Sidebar:** مع status badge (معتمد ✅ / قيد المراجعة ⏳)
- **Top Bar:** إشعارات + balance سريع
- **تصميم:** احترافي مع تركيز على البيانات

### الصفحات

#### 1. لوحة الأداء (`/guide/dashboard`)
| العنصر | الوصف | نوع الـ Chart |
|--------|-------|-------------|
| إجمالي الحجوزات | عدد + نسبة التغيير | Counter مع Sparkline |
| إجمالي الإيرادات | بالريال + نسبة التغيير | Counter مع Sparkline |
| التقييم العام | متوسط + عدد التقييمات | Stars + Bar Chart |
| البرامج الأكثر شعبية | Top 5 برامج بالحجوزات | Horizontal Bar Chart |
| الحجوزات الشهرية | آخر 6 أشهر | Line Chart |
| الإيرادات الشهرية | آخر 6 أشهر | Area Chart |

#### 2. برامجي (`/guide/programs`)
| العنصر | الوصف |
|--------|-------|
| فلترة بالحالة | مسودة / قيد المراجعة / منشور / معلق |
| كروت البرامج | صورة + اسم + حالة + عدد الحجوزات + تقييم |
| إجراءات سريعة | تعديل / إيقاف مؤقت / نسخ |
| زر إنشاء جديد | CTA بارز |

#### 3. إنشاء/تعديل برنامج (`/guide/programs/create`)
**Wizard بـ 5 خطوات:**

| الخطوة | المحتوى |
|--------|---------|
| 1. الأساسيات | العنوان (ar/en)، الوجهة، التصنيف، المدة |
| 2. المحتوى | الوصف، المسار (يوم بيوم)، الأنشطة، ما يشمله وما لا يشمله |
| 3. الوسائط | رفع 5 صور على الأقل مع drag & drop + ترتيب |
| 4. التسعير | سعر الشخص، الحد الأدنى والأقصى للمشاركين |
| 5. التقويم | التواريخ المتاحة + فترات عدم التوافر |

- **Live Preview** على الجانب يعرض البرنامج كما سيظهر للعميل

#### 4. تقويم التوافر (`/guide/calendar`)
| العنصر | الوصف |
|--------|-------|
| التقويم | عرض شهري مع drag-select للتواريخ |
| الألوان | أخضر (متاح) / أحمر (محجوز) / رمادي (غير متاح) |
| إضافة سريعة | click لإضافة/إزالة التوافر |

#### 5. المحفظة (`/guide/wallet`)
| العنصر | الوصف |
|--------|-------|
| الرصيد المتاح | بطاقة كبيرة بالريال |
| الأرباح المعلقة | مبالغ في Escrow |
| سجل المعاملات | جدول: التاريخ + البرنامج + المبلغ + الحالة |
| طلب سحب | Modal مع المبلغ + IBAN + تأكيد |

## ⚙️ لوحة الإدارة (Admin Dashboard) — 10 صفحات

### Layout
- **Sidebar:** Enterprise-style مع role-based menu items
- **Breadcrumbs:** مسار التنقل
- **تصميم:** داكن ومهني مع تركيز على الكفاءة

### الصفحات

#### 1. نظرة عامة (`/admin/dashboard`)
| الـ KPI | الوصف | نوع الـ Chart |
|---------|-------|-------------|
| إجمالي الحجوزات (اليوم/الشهر) | مع نسبة التغيير | Counter + Sparkline |
| إجمالي الإيرادات | عمولة + رسوم | Counter + Sparkline |
| المستخدمين الجدد | عملاء + مرشدين | Counter |
| طلبات معلقة | اعتماد مرشدين + مراجعة برامج | Badge Counter |
| النزاعات المفتوحة | عدد + أولوية | Counter + Priority Tag |
| رسم بياني | إيرادات آخر 30 يوم | Area Chart |
| توزيع الحجوزات | حسب الوجهة | Pie Chart |
| Top المرشدين | أعلى 5 بالحجوزات | Horizontal Bar |

#### 2. إدارة المستخدمين (`/admin/users`)
| العنصر | الوصف |
|--------|-------|
| جدول متقدم | Avatar + الاسم + النوع (Client/Guide/Admin) + الحالة + تاريخ التسجيل |
| بحث + فلاتر | بالاسم/الإيميل/الجوال + فلتر النوع والحالة |
| إجراءات | عرض التفاصيل / تعليق / تفعيل / حذف |

#### 7. المالية (`/admin/finance`)
| العنصر | الوصف |
|--------|-------|
| رصيد Escrow | إجمالي الأموال المحتجزة |
| عمولات المنصة | إجمالي العمولات المكتسبة |
| طلبات السحب | قائمة معلقة مع approve/reject |
| طلبات الاسترداد | Refund requests مع القرارات |
| تقرير مالي | قابل للتصدير CSV/PDF |

#### 10. الإعدادات (`/admin/settings`)
| القسم | المحتوى |
|-------|---------|
| نسبة العمولة | Input + preview |
| إضافات التسعير | CRUD للرسوم والضرائب (اسم + نوع + قيمة) |
| فترة الاحتجاز | عدد الأيام بعد الرحلة |
| مدة الإلغاء | عدد الساعات المسموحة |
| الحد الأدنى للسحب | بالريال |
| الأدوار والصلاحيات | Matrix: الدور × القسم × الإجراء |
