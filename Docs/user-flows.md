## Flow 1: رحلة العميل من الاكتشاف للحجز

```mermaid
flowchart TD
    A["🏠 الصفحة الرئيسية"] --> B["🔍 استكشاف البرامج"]
    A --> C["🗺️ صفحة الوجهات"]
    C --> D["📍 صفحة وجهة واحدة"]
    D --> B
    B --> E["📋 تفاصيل البرنامج"]
    E --> F{"مسجل دخول؟"}
    F -- لا --> G["🔐 تسجيل / دخول"]
    G --> E
    F -- نعم --> H["📅 اختيار التاريخ والعدد"]
    H --> I["💳 مراجعة ودفع"]
    I --> J["✅ تأكيد الحجز"]
    J --> K["📱 داشبورد العميل"]
    E --> L["💬 مراسلة المرشد"]
    E --> M["❤️ إضافة للمفضلة"]
```

### تفاصيل الخطوات
1. **الاكتشاف:** العميل يتصفح بدون حساب — يبحث بالوجهة والنشاط والتاريخ
2. **الاهتمام:** يفتح تفاصيل البرنامج — يشوف الصور والمسار والتقييمات
3. **القرار:** يقرر الحجز أو المراسلة أو الإضافة للمفضلة
4. **المصادقة:** يسجل/يدخل (OTP أو Email أو Social)
5. **الحجز:** يختار التاريخ والعدد → مراجعة التكلفة → الدفع عبر MyFatoorah
6. **التأكيد:** الحجز يتأكد تلقائياً ← إشعار للمرشد والعميل

## Flow 4: تدفق الحجز والدفع (Technical)

```mermaid
sequenceDiagram
    participant C as العميل
    participant W as الموقع (Next.js)
    participant A as الباك إند (NestJS)
    participant P as MyFatoorah
    participant E as Escrow

    C->>W: اختيار التاريخ والعدد
    W->>A: POST /bookings/initiate
    A->>A: حجز التوافر مؤقتاً (no_guide_overlap)
    A->>A: حساب التكلفة (سعر + إضافات الأدمن)
    A-->>W: booking_draft + تفاصيل التكلفة
    W-->>C: عرض ملخص الدفع

    C->>W: تأكيد الدفع
    W->>A: POST /payments/initiate
    A->>P: إنشاء جلسة دفع
    P-->>A: payment URL
    A-->>W: redirect URL
    W->>P: redirect العميل لصفحة الدفع
    P->>C: صفحة الدفع
    C->>P: إدخال بيانات البطاقة

    P->>A: Webhook: payment.success
    A->>A: تأكيد الحجز تلقائياً
    A->>E: حجز المبلغ في Escrow
    A->>A: إنشاء booking_price_snapshot
    A->>A: إرسال إشعارات (العميل + المرشد)
    A-->>W: booking confirmed
    W-->>C: صفحة التأكيد 🎉
```

```mermaid
flowchart TD
    A["العميل يطلب إلغاء"] --> B{"في فترة الإلغاء المسموحة؟"}

    E --> D
    D --> F["الأدمن يراجع الطلب"]

    G -- استرداد كامل --> H["💰 رد المبلغ كاملاً"]
    G -- استرداد جزئي --> I["💰 رد جزء من المبلغ"]
    G -- رفض --> J["❌ رفض مع السبب"]

    I --> K
    K --> L["إشعار للعميل والمرشد"]
```
